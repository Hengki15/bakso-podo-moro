BAKSO PODO MORO - VERSI ONLINE SUPABASE

Pelanggan: buka index.html
Admin: buka admin.html
Login admin: username admin | password admin123

Fitur:
- Menu online dari Supabase
- Pesanan pelanggan tersimpan online
- Admin tambah/edit/hapus menu
- Admin dapat mengganti foto menu
- Admin melihat pesanan dan total penjualan

Catatan keamanan:
Versi ini menggunakan publishable/anon key di frontend. Login admin masih berupa login demo di sisi browser, sehingga untuk produksi sebaiknya ditingkatkan dengan Supabase Auth dan policy RLS yang lebih ketat.
